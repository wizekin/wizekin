# Wizekin

**Practical digital tools for independent work.**

Wizekin is an independent software project focused on simple, thoughtful tools that help people move from complicated tasks to clear next steps.

### Featured project: ClearQuote Studio

[**Explore ClearQuote Studio →**](https://wizekin.web.app/clearquote/)

A free collection of browser-based tools and guides for freelancers planning project prices and client payments.

- **[Project pricing calculator](https://wizekin.web.app/clearquote/#calculator)** — estimate labor, expenses, contingency, discounts, taxes and deposits.
- **[Hourly rate calculator](https://wizekin.web.app/clearquote/guides/freelance-hourly-rate-calculator.html)** — estimate a baseline rate based on earnings goals and billable capacity.
- **[Deposit calculator](https://wizekin.web.app/clearquote/guides/freelance-deposit-calculator.html)** — split an agreed project total into the amount due upfront and the remaining balance.
- **[Freelance quote guide](https://wizekin.web.app/clearquote/guides/how-to-create-a-freelance-quote.html)** — learn what to include when presenting an estimate to a client.

The free calculators require no account. A separate, optional **$3 one-time downloadable quote/invoice toolkit** is also available through ClearQuote Studio.
